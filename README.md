# GrowVibe — Digital Marketing Agency Website

A premium, custom-designed Next.js 14 (App Router) + TypeScript + Tailwind
CSS + shadcn/ui site for a digital marketing agency (growvibe.io), with six
pages: Home, Services, Work (case studies), Pricing, About, and Contact.

Design system: near-black "ink" + off-white "paper" palette with a single
emerald accent, Space Grotesk headings paired with Inter body text, no
gradients, dependency-free scroll-reveal animations and count-up stats
(`src/components/reveal.tsx`, `src/components/animated-counter.tsx`).

## Step 1 — Install prerequisites

You need [Node.js](https://nodejs.org) version 18.18 or newer. Check your
version:

```bash
node -v
```

## Step 2 — Install dependencies

Unzip this project, open a terminal in the project folder, and run:

```bash
npm install
```

This downloads Next.js, React, Tailwind CSS, and the small set of shadcn/ui
building blocks (Radix primitives, `class-variance-authority`,
`tailwind-merge`, `lucide-react` icons) listed in `package.json`.

## Step 3 — Run the dev server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser. The
page auto-reloads as you edit files.

## Step 4 — Explore the project structure

```
src/
  app/
    layout.tsx          # Root layout: fonts, <Navbar/>, <Footer/>
    globals.css         # Tailwind + shadcn design tokens (colors, radius)
    page.tsx             # Home page
    services/page.tsx    # Services page
    about/page.tsx        # About page
    contact/page.tsx      # Contact page (renders <ContactForm/>)
  components/
    navbar.tsx           # Sticky responsive nav with mobile menu
    footer.tsx            # Site footer
    contact-form.tsx      # Client-side contact form (see Step 6)
    ui/                    # shadcn/ui primitives: button, card, input,
                            # textarea, label, badge
  lib/
    utils.ts             # `cn()` helper used by every ui component
```

## Step 5 — Customize content

Everything is plain React/TypeScript, so you can edit text directly in each
page file:

- **Branding**: the agency is named "NovaReach" — search-and-replace it in
  `src/components/navbar.tsx`, `src/components/footer.tsx`, and
  `src/app/layout.tsx` (page title/description).
- **Colors**: edit the HSL values in `src/app/globals.css` under `:root`
  (e.g. `--primary`) to match your brand.
- **Services, stats, testimonials, team bios**: each page (`page.tsx`) has
  a small array of data (e.g. `SERVICES`, `TESTIMONIALS`, `TEAM`) near the
  top of the file — edit those arrays directly.
- **Logo**: currently a Lucide "Rocket" icon in a colored box
  (`navbar.tsx`/`footer.tsx`). Swap it for an `<Image>` of your real logo
  from the `public/` folder.

## Step 6 — Wire up the contact form

`src/components/contact-form.tsx` currently just simulates a submission
(a fake delay, then a success screen) — no email is actually sent. To make
it real, pick one:

- **Simplest**: use a form backend like [Formspree](https://formspree.io)
  or [Resend](https://resend.com) — point the `handleSubmit` function at
  their API instead of the `setTimeout` placeholder.
- **Full control**: add a Next.js API route at
  `src/app/api/contact/route.ts` that sends an email (e.g. via Resend or
  Nodemailer) or saves to a database, and call `fetch("/api/contact", ...)`
  from `handleSubmit`.

## Step 7 — Add real images

Add your own photos/illustrations to the `public/` folder and reference
them with Next's `<Image>` component for automatic optimization:

```tsx
import Image from "next/image";
<Image src="/team-photo.jpg" alt="Our team" width={800} height={600} />
```

## Step 8 — Deploy

The easiest path is [Vercel](https://vercel.com) (made by the Next.js
team): push this project to a GitHub repo, import it on vercel.com, and it
deploys automatically. Netlify and Cloudflare Pages also support Next.js.

## Notes

- This project was hand-authored file-by-file rather than generated by
  `create-next-app`/`npx shadcn@latest add`, because the environment it was
  built in didn't have package-registry access to run those CLIs. Every
  file was written to match current Next.js 14 App Router and shadcn/ui
  conventions and checked with a TypeScript/JSX syntax pass, but since
  `npm install` / `npm run build` couldn't be run there, please run
  `npm run build` yourself after `npm install` as a final check —
  if anything surfaces, it's most likely a minor dependency-version
  mismatch, easy to fix.
